# 南桥街：最后一场

手机网页优先。双击 `Publish-Game.cmd` 提交并推送到 GitHub，自动部署 Pages；部署成功后双击 `Play-Game.cmd` 试玩。详见 [发布说明](docs/PUBLISHING.md) 和 [美术基调](docs/ART_DIRECTION.md)。

原创像素横版清关动作游戏原型。首页 `/` 直接进入游戏，旧试玩地址 `/nanqiao` 继续可用。

## 运行

需要 Node.js 22.18+。首次运行 `npm install`，然后执行 `npm run dev -- --host 0.0.0.0 --port 5173`。

电脑打开 http://localhost:5173/；手机连接同一局域网，使用电脑的局域网 IP 和端口 5173，推荐横屏。

## 内容与操作

目前只开放陈野一个角色。阿拓和小满的数值、招式和分支台词都还在代码里（`PLAYABLE` 控制放出哪几个），需要时改一行就能加回来。第一章包含三段街头清场、十个小兵和铁头 Boss，以及开场、Boss 前和结尾剧情。

第二章河边货场已加入：11 个小兵、投掷手、长腿 Boss，以及可举起投掷的木箱。绿标木箱破碎掉补给，地面木箱能挡罐子。通关夜市可继续，也能在选人页直接选第二关。练习场可测试全部现有敌人和木箱。

第三章旧商业街与第四章黑桥赛场已加入原型：分别是 12 个小兵加陆川 Boss、13 个小兵加韩骁 Boss。四关都能从上一关通关继续，也能在选人页直接选；窄屏关卡入口折成两行两列。第四关结束显示原型完结说明，不再提供下一关按钮。

陆川（第三关）按固定顺序轮换两种打法：0.5 秒前摇的短连拳，和侧移半步之后的反冲反击。连拳打完、反冲结束或反击落空都开放 0.8 秒破绽；血量过半连拳从 2 下变 3 下、间隔更短。他不读取玩家输入，招式顺序每次一样。

韩骁（第四关）把前三关的招式收在一个人身上：连拳、长踢、冲撞按固定顺序轮换，各有独立前摇和预警范围。破绽 0.7 秒，比前三关都短；血量过半前摇从 0.55 秒缩到 0.44 秒、连拳多一下。420 点生命，第四关三波同时存活上限提到 3／4／4。

第三、四关沿用现有的四种小兵和木箱，没有新增兵种或武器。天桥和擂台用背景与护栏表现高度，仍是同一个战斗平面，没有高低层或坠落。

关卡配置集中在 `game/street/chapter-data.ts`（名称、Boss、主题、木箱、街道边界），剧本集中在 `game/street/story-data.ts`（开场、Boss 战前、结尾，按章节和所选角色取数据）。Boss 数值在 `game/street/encounter-data.ts`。HUD 显示场上这个 Boss 的名字和它已经决定要出的招，练习场也一样。

WASD / 方向键移动，J 连打，K / 空格跳跃，U 闪避，I 消耗 50 怒气释放绝招，Esc 暂停。手机使用摇杆和四个动作按钮：攻击、跳跃、闪避、绝招。没有抓投键：不按攻击走进小兵就会自动抓住，按攻击扔出（推反方向往身后扔），跳跃／闪避／绝招松手，挨打或 1.2 秒后自动松开，Boss 抓不住。

闪避：推方向时向该方向撤步，摇杆回中时向身后撤步并保持朝向。移动与无敌各180ms，完整动作340ms，两次启动至少间隔550ms；收招后可接攻击。不会打断出拳或硬直，但支持既有180ms末段输入缓冲；空中和举箱时不可用，不消耗怒气。参数是本项目初版，不是参考游戏数值。右侧五键使用弧形布局，跳跃紧贴大攻击键左下方；手机显示动作提示，不显示键盘字母。

第四批战斗改进验证：101项模拟测试、TypeScript检查、Pages构建通过。新增出兵队列与上限、入场保护、两章全流程、Boss自然破绽与伤害倍率、暂停／重置测试，保留前三批回归。浏览器连接失败，未取得本轮画面截图，尚未做真实手机手感验收。Pages工作流已纳入全部五组战斗测试。

第三、四关原型验证：114项模拟测试（新增13项在 `game/street/chapter.test.mjs`）、TypeScript检查、Pages构建通过。新增测试覆盖四关串联与到此为止、第三第四关全流程通关、失败重试留在本关、两个Boss的招式轮换与必然开放的破绽、1/30～1/120帧率下的破绽时长、减伤倍率、过半血的连拳段数、练习场Boss名字、剧本对三个角色的完整覆盖。桌面浏览器已实际进入两关并确认背景、HUD和陆川的侧移／破绽表现；未做真机手感验收，也未在触屏上测试新关卡。Pages工作流已纳入全部六组战斗测试。

出兵配置集中在 `game/street/encounter-data.ts`。四章分别为10／11／12／13个小兵，每章三波同时存活上限为2／3／3、2／3／3、3／3／3、3／4／4；首次填到上限，有空位后等待600ms逐个补人。活着的击飞／倒地敌人和入场敌人仍占上限，死亡身体不占。增援在距玩家至少90逻辑单位的战区边缘选择较空位置，450ms入场提示期间不能攻击、受击、被抓或预约围攻位。队列空、活人全灭且死亡表现结束后才能前进，HUD剩余数包含待援；练习场维持手动数量，不自动补兵。

第四批Boss破绽：铁头完成冲撞后开放1.2秒，长腿长踢有效段180ms结束后开放950ms。破绽中承受完整伤害，其他时候只承受25%；普通受击硬直或被打断的蓄力不产生破绽。普通拳、绝招、投箱、飞行撞人统一走此倍率，Boss仍不能被抓投，仍能被重击击飞，不新增霸体。命中不会刷新破绽或缩短其行动锁，击飞／倒地也不延长破绽；暂停与命中停顿冻结计时。血条颜色、脚底绿圈、倒计时及HUD文字区分可反击窗口和减伤状态。

普通近战敌人使用围攻位：左右各一个攻击位，外围分散等待位；预约位置并到位后才能起手，同时保留全场最多两名敌人蓄力／冲锋／长踢的限制。攻击后退回等待位，受击／击飞／死亡释放位置供其他敌人补上。越界位置不分配，玩家大幅移动后重新分配；换边时绕过玩家。远程兵和两个Boss不使用普通近战站位。

普通三连击只在命中后推进：连续命中两拳后才获得第三击上勾拳；空挥重置后续段数，一拳命中多人只推进一次。命中后的650ms内可以接下一段，超时／受击中断；奔跑重击和空中攻击不积攒普通三连击。按住攻击仍可连打，手机输入与五键布局不变。

第二批招式参数集中在 `game/street/combat-data.ts`：三个角色的普通三段、奔跑重击和空中踢分别配置前摇、有效判定、收招、前进区间、攻击高度与连招窗口。有效期内持续检测，但每个目标每招只受伤一次；前摇和收招不造成伤害。命中后窗口内点攻击会留到窗口末尾接下一段，不立即取消；跳跃等主动动作优先于连打，空挥不能提前取消收招。渲染按战斗状态表现蓄力、出拳和回收，后续序列帧沿用同一时间轴。

跳跃与击飞使用独立 `height / heightVelocity`，地面 `y` 仍负责前后排、围攻位置与绘制排序。起跳准备40ms，重力600；陈野／阿拓／小满起跳速度200／180／215，跳高约33／27／39逻辑单位，普通落地恢复80ms。起跳和低空仍会挨地面拳，足够高时躲过低攻击；空中被高攻击命中会中断招式并自然下坠。起跳准备期间保留已排队的攻击，避免低帧率吞掉“跳→打”；空中不能捡地面补给。

击飞落地后倒地300ms、起身180ms，完成后才恢复围攻与行动。当前不做空中追击／倒地追加伤害，不能重复抓取尚未站稳的敌人；死亡角色落地后消失，不会重新起身。

第三批力度层次：敌人的失衡值与水平击退速度分开计算。普通拳+60、空中踢+180、上勾拳+600、奔跑重击／抓投+1200；达到600时击飞并清空积累。上勾拳、奔跑重击和抓投直接达到阈值，普通拳只轻推；绝招+600、投箱+300。2秒未再受击后每秒恢复180失衡值，暂停／命中停顿冻结恢复。两个Boss仍可被击飞，失衡与击退不受其减伤倍率影响，玩家受伤规则不变。

击飞、上勾拳和抓投统一按实际飞行路线碰撞：同排、身体高度相交且移动足够快才撞倒沿途敌人，每人基础25连带伤害（Boss再按破绽倍率结算）。投掷不再出手瞬间伤害整排。飞行水平阻力独立于地面击退，使用路径扫掠避免低帧率穿人；同一次飞行对同一目标最多结算一次，二次被撞者不继续传播伤害，也不推进玩家普通三连击。致死击飞的身体仍能撞人，死亡计数不重复。

击飞撞到当前战区左右边界时，水平速度反向减半，每次飞行最多反弹一次；不追加撞墙伤害，也不重新抬高或延长腾空时间。落地后正常倒地起身。练习场开启判定范围可查看敌人失衡值／600，撞人和撞墙有文字反馈。各批参数为本项目初版，不是参考游戏参数复刻。

界面统一到一套设计变量（`app/nanqiao/street.css` 顶部的颜色、间距、按钮单位），不再靠层层覆盖调样式。战斗中隐藏标题栏，把高度让给画面；HUD 左侧是角色名、带掉血残影的血条和带50刻度的怒气条（满50时高亮并让绝招键亮起），右侧是关卡、三段清场进度点和全屏／声音／暂停图标键，Boss 血条与破绽状态改由 DOM 居中显示，画布只保留战场内的提示。

五个动作键按功能配色：攻击暖橙、跳跃冷灰、闪避青、绝招暗红、抓投橄榄；抓投可用和绝招就绪显示青色亮边，闪避冷却用扇形扫描表示。选人页改成角色卡（画像、定位、力量／速度条）加分段式关卡选择，剧情页用说话人标签和提示块分层；练习场用开关和下拉重排。手机横屏下选人、剧情和练习场都在一屏内排完，不需要滚动。

顶部“全屏”按钮可进入或退出浏览器全屏（需浏览器支持并由点击触发）。横屏按屏幕比例扩展场景，两侧触控悬浮在下角；人物保持原比例。

手机战斗调整：摇杆中心16%死区，单次推满仍走路；左右同方向在280ms内快速推两次（中间回中或松手），第二次保持即奔跑。回中、松手、反向或纵向走位停止奔跑；暂停与触摸取消清除双推记录。电脑按住Shift配合方向键奔跑。奔跑中新点攻击触发重击，命中造成两倍基础伤害并直接击飞（含Boss），以初速度200腾空约667ms，再倒地起身；空挥不击飞。上述时间不含命中停顿。按住攻击随后接普通连打，不连续自动冲刺；奔跑重击与空中攻击不占普通三连击段数。举箱和空中不奔跑。抓投可用时亮起边框。

滑出规则：按住攻击可连打；手指越过圆形攻击键边缘立即停止连打、清除待发攻击，但已出手的一拳正常收完。滑回不续打，滑入其他按钮不触发，需抬指再点；取消触摸或丢失捕获也停止。普通抬指保留单次点按的有效缓冲，不会吞掉轻点。其他手指操作摇杆不影响攻击手指。

动作优先级：除命中连招窗口外，当前出招／受击硬直不被强制取消；180ms末段缓冲最多保留一个主动动作和一次攻击，招式窗口内的续拳至少保留到该窗口关闭。主动动作冲突时按“闪避 > 绝招 > 跳跃 > 抓投”取最高优先级，再执行普通攻击；按住连打优先级最低。跳跃与攻击分开保存，不论缓冲中谁先到都先跳后打；过期、受击、暂停时清除待发输入。普通拳前摇依角色和段数为40～90ms，奔跑重击65ms，实际命中才有停顿和击退。明确移动方向时不自动转身打背后敌人。近身抓投支持方向投掷，空抓不锁动作，空中不能抓投。此轮为自定义手感初版，并非参考游戏参数复刻；自动测试通过不代表真实手机手感验收。

靠近木箱、身边没有敌人时按 J（攻击）举起，再按 J 扔出。按住攻击不会举起后立刻扔出。奔跑攻击结束后会带一段向前滑行的惯性。举箱时不能跳跃，受击会掉箱。

角色目前是程序绘制的像素样稿；后续章节、最终动画、存档、武器拾取和 Poki SDK 尚未实现。

## 工程

- `app/page.tsx`：首页入口。
- `app/nanqiao/`：游戏页面、操作、剧情和样式，同时兼容旧试玩地址。
- `game/street/`：独立战斗模拟、Phaser 渲染和模拟测试。
- `docs/NANQIAO_PROTOTYPE.md`：实现范围与原型边界。
