# 南桥街：最后一场

手机网页优先。双击 `Publish-Game.cmd` 提交并推送到 GitHub，自动部署 Pages；部署成功后双击 `Play-Game.cmd` 试玩。详见 [发布说明](docs/PUBLISHING.md) 和 [美术基调](docs/ART_DIRECTION.md)。

原创像素横版清关动作游戏原型。首页 `/` 直接进入游戏，旧试玩地址 `/nanqiao` 继续可用。

## 运行

需要 Node.js 22.18+。首次运行 `npm install`，然后执行 `npm run dev -- --host 0.0.0.0 --port 5173`。

电脑打开 http://localhost:5173/；手机连接同一局域网，使用电脑的局域网 IP 和端口 5173，推荐横屏。

## 内容与操作

三个可选角色：陈野、阿拓、小满。第一章包含三段街头清场、十个小兵和铁头 Boss，以及开场、Boss 前和结尾剧情。

第二章河边货场已加入：11 个小兵、投掷手、长腿 Boss，以及可举起投掷的木箱。绿标木箱破碎掉补给，地面木箱能挡罐子。通关夜市可继续，也能在选人页直接选第二关。练习场可测试全部现有敌人和木箱。

WASD / 方向键移动，J 连打，K / 空格跳跃，U 闪避，L 近身抓投，I 消耗 50 怒气释放绝招，Esc 暂停。手机使用摇杆和五个动作按钮：攻击、跳跃、闪避、绝招、抓投／举箱。

闪避：推方向时向该方向撤步，摇杆回中时向身后撤步并保持朝向。移动与无敌各180ms，完整动作340ms，两次启动至少间隔550ms；收招后可接攻击。不会打断出拳或硬直，但支持既有180ms末段输入缓冲；空中和举箱时不可用，不消耗怒气。参数是本项目初版，不是参考游戏数值。右侧五键使用两排布局，跳跃紧邻大攻击键；手机显示动作提示，不显示键盘字母。

本轮闪避验证：33项模拟测试、TypeScript检查、Pages构建通过；浏览器连接失败，尚未完成截图和真实手机手感验收。

顶部“全屏”按钮可进入或退出浏览器全屏（需浏览器支持并由点击触发）。横屏按屏幕比例扩展场景，两侧触控悬浮在下角；人物保持原比例。

手机战斗调整：摇杆中心16%死区，单次推满仍走路；左右同方向在280ms内快速推两次（中间回中或松手），第二次保持即奔跑。回中、松手、反向或纵向走位停止奔跑；暂停与触摸取消清除双推记录。电脑按住Shift配合方向键奔跑。奔跑中新点攻击触发冲刺攻击，按住攻击随后接普通连打，不连续自动冲刺。举箱和空中不奔跑。右侧攻击放大，跳跃位于附近，抓投可用时亮起边框。

操作输入允许180ms末段缓冲（只保留最后一个动作）；普通出拳50ms后判定命中，冲刺65ms后判定，实际命中才有停顿和击退。第三击和冲刺增加反馈；明确移动方向时不自动转身打背后敌人。近身抓投支持方向投掷，空抓不锁动作，空中不能抓投。此轮为自定义手感初版，并非参考游戏参数复刻；自动测试通过不代表真实手机手感验收。

靠近木箱按 L（抓投）举起，J（投箱）扔出，L（放下）落地。举箱时不能跳跃，受击会掉箱。

角色目前是程序绘制的像素样稿；后续章节、最终动画、存档、武器拾取和 Poki SDK 尚未实现。

## 工程

- `app/page.tsx`：首页入口。
- `app/nanqiao/`：游戏页面、操作、剧情和样式，同时兼容旧试玩地址。
- `game/street/`：独立战斗模拟、Phaser 渲染和模拟测试。
- `docs/NANQIAO_PROTOTYPE.md`：实现范围与原型边界。
