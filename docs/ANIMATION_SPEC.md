# 南桥街：最后一场 — 动画规格表

更新：2026-09-23。配合 `ART_DIRECTION.md` 使用：造型、配色、比例、视角以那份为准，本文只管**画哪些动作、每个动作几帧、每帧多长、打击在哪一帧**。

所有时长来自 `game/street/combat-data.ts` 与 `game/street/encounter-data.ts` 的实际数值。数值改了，这张表要同步改。

## 一、总则

### 画布与锚点

| 体型 | 单帧画布 | 脚底锚点 | 站立高度 | 适用 |
| --- | --- | --- | --- | --- |
| 普通 | 128×96 | (48, 90) | 约 64 | 陈野、拳手、快手、投掷手、格挡兵、扑抓兵、陆川、韩骁 |
| 壮汉 | 144×112 | (56, 104) | 约 74 | 壮汉、铁头 |
| 长腿 | 176×112 | (48, 104) | 约 70 | 长腿（长踢要伸出 105 像素） |

- 同一角色**所有帧画布一样大**，脚底中心永远落在锚点那个像素上。攻击肢体往前伸，不要为了装下而挪动身体。
- 一律**朝右画**，朝左由程序水平镜像（`ART_DIRECTION.md` 已定）。避免服装文字和单侧标志。
- 上下走位复用左右走路动画，不画八方向。
- 影子是程序画的椭圆，帧里**不要画影子**。

### 时间：用"每帧毫秒数"，不用统一帧率

我们的招式按阶段计时（前摇 / 有效 / 收招），这些阶段很多只有 45–80 毫秒，套不进 12fps 这种固定帧率。所以本表**每一帧单独给时长**，美术在 Aseprite 里逐帧填时长即可。

两条硬规则：

1. **帧的分界必须落在阶段分界上。**有效帧（表里标 ★ 的）必须恰好在前摇结束时出现、在有效段结束时切走，因为伤害判定就是那段时间。想多加几帧预备动作，可以把前摇拆成两帧，但**总时长不变**；要改总时长，是改战斗设计，得先改 `combat-data.ts`。
2. **动画时间跟随模拟时间。**命中停顿、必杀定格、最后一击慢动作时，动画会自动定格或变慢，美术不用单独画"停顿帧"。

### 文件格式

- 用 **Aseprite**。每个角色一个 `.aseprite` 源文件，导出 PNG 图集 + JSON（Array 格式，带 frame tags 和每帧 duration）。Phaser 能直接读这种导出。
- **tag 名必须和本表的"状态键"一字不差**，程序按 tag 名找动画。
- 透明背景，硬边像素，帧与帧之间留 1 像素透明间隔。

## 六、模拟层要配合改的地方（重写渲染层之前做）

现在模拟层的姿势名是边做边加的，有几处一个名字对应好几种画面，美术画了也接不上。重写渲染层前先改成下面这样：

1. **`hurt` 拆成三个**：`hurt`（普通受击）、`dazed`（Boss 破绽、扑抓兵扑空或被挣脱后的僵直）、`grabbed`（被陈野抓住）。现在这三种全叫 `hurt`。
2. **`throw` 拆成四个**：`throw`（陈野扔人）、`toss`（陈野扔箱）、`can_throw`（投掷手）、`slam`（扑抓兵摔人）。
3. **预警按招式区分**：小兵仍是 `wind`，扑抓兵是 `crouch`；Boss 用 `wind_jab` / `wind_charge` / `wind_kick` / `wind_combo`。现在 Boss 的招式信息在 `move` 和 `bossMove` 字段里，要合并成一个姿势名。
4. **格挡兵挡住那一下要有姿势**：现在只飘一个"格挡"字，身体没有反应。加 `block`。
5. **陆川、韩骁连拳分左右手**：`punch_l` / `punch_r` 交替。
6. **`walk`、`run`、`carry_*`、`guard_*` 由渲染层推导**，不进模拟层：
   - 有移动输入就是 `walk`，`sim.running` 为真就是 `run`
   - 举着箱子时换成 `carry_idle` / `carry_walk`
   - 格挡兵在不出手、不受击时换成 `guard_idle` / `guard_walk`
7. **`jump`、`launched` 按竖直速度选帧**，不按时间。

## 七、制作顺序与验收

1. **陈野第一批**（约 30 帧）→ 接进游戏实机看，确认比例、锚点、节奏都对，再往下做。
2. 陈野第二批 → 小兵通用骨架 → 各兵种额外动作 → 壮汉。
3. 铁头 → 长腿 → 陆川 → 韩骁（按关卡顺序，做一个接一个）。
4. 陈野第三批和特效最后做。

**全部合计约 276 帧**（不含小兵换头换衣的变体）。

验收沿用 `ART_DIRECTION.md` 的"素材验收"，另外加三条：

- **★帧对得上**：在练习场打开"显示判定范围"，★帧出现的那一刻，拳脚要落在黄框里。
- **预警看得见**：在手机实际大小下，每个 `wind` / `crouch` / `wind_*` 都要能在不看提示字的情况下认出"它要出手了"。
- **破绽看得见**：`dazed` 要一眼和站立、受击区分开。
