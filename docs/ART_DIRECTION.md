# 南桥街：最后一场 — 美术基调

更新：2026-09-23。陈野造型改定为约三头身；本文取代此前约四头身的约定。

## 产品方向

手机网页优先，电脑浏览器兼容，未来目标 Poki。当前先完善第一章原型与手机操作；美术逐步替换，不等待完整素材才开发。单机运行，不依赖自建游戏服务器。

主体验为横屏清版动作：选角色 → 清理小兵 → 前进 → Boss → 短剧情。手机竖屏保留可用入口和横屏提示，不把强制旋转作为启动门槛。

## 世界与情绪

架空九十年代中国南方旧街区。夜市、修车铺、旧拳馆、街机厅、河边货场。生活气息、旧友重逢、略带喜感的街头冲突。避免赛博朋克、霓虹铺满画面、现代战术装备与写实血腥。

背景冷蓝灰，灯笼和店面暖黄橙。人物轮廓清楚，敌人预警、拾取物、角色和背景之间必须容易区分。装饰不能覆盖拳脚和脚底位置。地面上能被撞塌的蒸笼摊、自行车、塑料凳另见 `PROPS_SPEC.md`。

## 像素规格

- 16 位街机像素观感，原创造型。不是照搬 FC 的颜色与分辨率限制。
- 当前原型逻辑画布 480×270。手机需保持纵横比，像素采样使用 nearest-neighbor；屏幕无法整数倍铺满时接受清晰度折中，不拉伸角色比例。
- 陈野采用约三头身的成年街头人物比例：发顶到下巴算一个头长，约占站立全高的三分之一；大头、紧凑躯干、短而结实的腿，拳头和鞋轮廓清楚。以已确认的参考图为准，不机械拉伸到精确整数比例。
- 保留成年中国青年的眉骨、下颌、肩膀和神态，不继续放大眼睛、缩短下巴或把四肢画成幼儿体型。亲和与喜感来自比例，力量来自重心和动作姿势。
- 普通人物沿用相近的夸张程度，以肩宽、胖瘦、发型和姿态区分；壮汉和 Boss 单独设计轮廓，最终造型仍需确认。壮汉比普通角色高约 15%、肩宽约 50%。
- 站立高度暂沿用约 64 逻辑像素，作为实机试装尺寸；角色头身比例和屏幕显示尺寸分别验收，不能为凑尺寸拉长腿。画布与锚点暂沿用 `ANIMATION_SPEC.md`，实机确认后再统一调整。
- 每种材质两到三级明暗，有限色板、硬边像素、统一左上光。轮廓深蓝黑，不使用柔光、模糊渐变或像素滤镜。
- 游戏文字和操作按钮用 DOM 保证手机可读，不强迫小字号中文也使用像素字。

## 视角与动画

主要视角是朝右斜侧面的战斗站姿，脸朝右，部分胸口可见。接近水平的镜头，不是俯视或等距视角。动作允许自然转体，不锁死为严格 45 度。

陈野先做正面、朝右斜侧面待机、朝右正侧面、背面四视图。敌人先在一张图中各做一个朝右斜侧面待机姿势；必要的转背、摔倒角度在动作制作阶段补。

左向初版使用水平镜像，避免服装文字和明显的单侧标志。上下移动复用左右朝向的走路动画。无需八方向动作集。

角色最终采用序列帧，背景灯笼与界面使用程序动画。每个动作画几帧、每帧多长、打击落在哪一帧，见 `ANIMATION_SPEC.md`。先完成陈野待机、走路、出拳、受击，再做跳踢、抓投、绝招、倒地。每个动作先确认关键姿势，再补中间帧，不要求生成器一次完成所有人物所有动作。

动作中头、躯干、大腿、小腿和鞋保持同一尺寸。步幅由关节角度和重心变化产生，不靠拉长腿；转体、屈膝和透视变化可以改变投影高度，不能逐帧独立缩放去强行对齐。

使用视频生成时，按相关动作分组，一段视频可以提供多个动画状态，不要求每个状态单独生成视频。优先组合“待机 → 第一拳 → 第二拳 → 上勾拳 → 回到待机”“起跳 → 空中姿势 → 落地”“受击 → 击飞 → 倒地 → 起身”等自然动作链。walk、run 可放在同一源视频的不同段，但每段都要留出至少两个完整稳定周期，转场段不作为循环素材。

每组先写清动作顺序与大致时间段，固定角色造型、镜头、比例和背景，保留起手、有效姿势与收势。攻击可以比游戏内速度慢，方便抽取关键姿势；接入时重新按战斗时间轴配置。连招中的每一拳都要有可辨认的分界，允许单独停止和收回护架；缺少的收势或衔接姿势需要补做，不能默认完整连招能无损拆成独立招式。

15 秒作为一组动作展示的尝试长度，不承诺一次覆盖陈野全部动作。遗漏或变形的动作单独补做，不必重生成整套。生成器未必准确遵守秒数，切分以实际动作事件为准。视频经抽帧、循环检查、背景处理和统一尺寸后才能接入游戏；源视频数量、帧率和周期不直接替代动画状态数、目标帧数或战斗时长。豆包 walk 提示词见 [陈野三头身行走视频提示词](art/chen-walk-video-prompt.txt)。

## 两次生成流程

1. 陈野单独生成四视图并确认，作为全游戏的角色风格基准。
2. 附上已确认的陈野图，生成五个敌人的朝右待机合照。统一比例尺与像素密度，各人分区、完整全身、足底对齐。
3. 分别裁切角色作为后续动作参考，不从纯文字反复重设计人物。

设定图采用纯浅灰蓝背景，方便辨认轮廓；正式游戏帧应整理为透明背景。AI 输出尺寸、透明度和网格不一定精确，必须检查、规范化后再接入游戏。

## 素材验收

- 在真实手机显示大小下能分辨角色和攻击前摇，不只看放大图。
- 脚底锚点、角色比例、服装和发型在帧间稳定；攻击肢体不被画布裁掉。
- 陈野以三头身基准核对；不能待机短腿、走跑长腿。缩小到实际游戏尺寸检查脸、拳带与鞋的辨识度。
- walk 必须检查左右脚各一次落地、支撑与摆动的交替，以及首尾衔接；先播放再验收，不以静态排列整齐代替动作合格。
- 受击、倒地、普通站立的轮廓明显不同，轻拳和重击有不同姿态。
- 背景细节不能抢过角色，特效不能遮住敌人预警。
- 当前程序像素样稿不代表最终逐帧美术；以实机替换后的表现验收。
