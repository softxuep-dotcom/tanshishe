# 战斗完善记录与验收

更新：2026-09-24。手机网页优先；本文记录本轮已实现的规则和仍需完成的品质工作。早期原型文档中的旧数值，以当前代码和这份更新为准。

## 龙卷风

- 手机：按住方向盘左、右或带横向的斜方向，再点技能。电脑：A/D 或左右箭头 + I。
- 按下技能时确定指令；即使动作缓冲期间松手或改方向，也不会变成解围或满怒必杀。
- 消耗 50 怒气。满怒时推方向依然发龙卷风，只消耗 50；回中点技能保留原 50 怒近身解围 / 100 怒必杀。只推上、下也算原技能。
- 起手 120ms，出手后收招 280ms；施放时站定，前 180ms 保护，收招剩余时间可被反击。不是持续无敌。
- 从身前 20 个逻辑像素处放出，以 280 像素/秒前进，中心最多移动 265 像素，遇当前战区边界消失。碰撞半径 18，同排容差 25。
- 每个敌人每道龙卷只结算一次：32 伤害，水平击退 210，起飞速度 185。穿透人群；被这招击飞的人不再产生身体连带伤害，避免对同一排重复结算。
- 可接一次空中追击，沿用既有追击上限。倒地、起身、刚入场的敌人受保护；身体高于 62 像素时不命中。
- Boss 在霸体期间受伤但不会被打断、击飞；破绽期间才能击飞。满怒必杀仍有原来的破霸体用途。
- 暂停和命中停顿冻结技能。受伤会取消尚未发出的龙卷，已经发出的继续飞。重新开始、换章、换战区、切换陪练会清理技能。

参数集中在 `game/street/combat-data.ts` 的 `TORNADO`。当前使用程序绘制的旋风、施放姿势和独立音效；后续序列帧按相同时间线接入，不通过改播放速度偷改判定。

## 本轮战斗修正

1. **绕背有效。**普通拳手、快手、壮汉、护架兵按蓄力时的朝向出拳，不能用背后判定打中已经绕开的玩家。
2. **起身反击遵守围攻限制。**最多两名敌人同时准备或执行攻击。多名敌人一同起身时，其余至少等待 350ms；实际反击显示提示。起身快招仍有 180–280ms 前摇，难度还需真人试玩调节。
3. **闪避缓冲能接住命中停顿。**前摇、有效帧和命中停顿中按下闪避，进入可取消的后摇后立即执行；不会强行跳过攻击有效帧。后续仍能接闪避突进和普通连击。

## 手机操作

- 844×390 横屏方向盘约 169px，较之前中心上移约 26px。
- 390×844 竖屏约 133px，方向盘额外上移 14px。
- 按实际视口缩放；320px 窄屏也保持左右触区分开，动作键约 46px 以上。
- 技能键随方向显示“龙卷风”；中立显示“技能”或“必杀”。

## 距离商业品质仍需完成

这轮完善输入与战斗规则，并不宣称已达到商业游戏品质。后续以完整一关连续试玩为验收对象：

1. **角色动作接入：**完整的蓄力、接触、收势、受击、击飞、倒地与起身序列帧。先完成陈野与一种敌人，确认脚底锚点、出手距离和接触姿态，再铺到全角色。
2. **敌人协同与关卡节奏：**用近战、游斗、护架、投掷、扑抓组合安排压力和喘息；检验玩家是否需要走位、破防、闪避和选时机，而不是加血量拖时长。
3. **打击反馈：**区分轻击、重击、破防、撞墙的接触音、受击姿势与特效；目前合成音和占位角色仍有限。
4. **真机调校：**在实际 Android/iPhone 上连续玩完整关卡，记录误触、丢指令、被遮挡的敌人、受击原因不清和帧时间尖峰。以这些现象迭代数值，不只看测试通过数。
