# 南桥街：最后一场 — 四章原型

入口：`/`，兼容原试玩地址 `/nanqiao`。项目仅保留南桥街游戏，旧游戏代码与文档已移除。发布目标为 GitHub Pages，推送 main 自动部署；详见 `PUBLISHING.md`。

## 已实现

- 选人页的练习场入口：三名角色，拳手/快手/壮汉/投掷手陪练与铁头/长腿/陆川/韩骁四个 Boss，1～4 人；无敌、停止陪练行动、回满生命、补满怒气、重置、判定范围显示。打开设置暂停，练习清场后不自动进关。普通模式不继承练习开关。练习场提供两只木箱。HUD 显示场上这个 Boss 的名字，不是当前章节的 Boss。
- 后续角色按序列帧动画制作；凳子、棍棒等短期武器暂不开发。护架拳手尚未实现。
- 第二关河边货场：三个清场区域、11 个小兵和长腿 Boss，独立河岸/吊机/集装箱背景与剧情。从夜市结尾继续，或选关直接进入；重试留在本关，进入新关恢复生命。
- 投掷手保持距离、预警后水平投罐；可上下错位或跳跃躲避，用地面木箱挡住罐子。
- 木箱：靠近且身边没有敌人时按攻击举起、再按攻击投出、抓投放下；移动减速，举箱时不能跳，受击会掉箱。贴身小兵优先于木箱，Boss 不可抓投。投箱使用沿移动线段的碰撞检测，首次撞敌后破碎，对邻近敌人产生范围伤害；绿标箱破碎掉落 +30 生命补给。
- 长腿：约 0.8 秒长踢前摇、前方范围预警、出腿后的反击窗口；可用投箱打断。没有完整跳踢动作集。
- 第三关旧商业街：三个清场区域、12 个小兵和陆川 Boss，卷帘店面与天桥护栏背景，按所选角色分支的战前对话。
- 陆川：0.5 秒前摇的短连拳（血量过半从 2 下变 3 下），以及侧移半步后的反冲反击。连拳打完或反冲结束都开放 0.8 秒破绽，反击落空同样开放。按固定顺序轮换招式，不读取玩家输入。
- 第四关黑桥赛场：三个清场区域、13 个小兵和韩骁 Boss，观众席、吊灯与擂台绳背景；同时存活上限提到 3/4/4。
- 韩骁：按固定顺序轮换连拳、长踢和冲撞——把前三关 Boss 的招式收在一个人身上。破绽 0.7 秒，比前三关都短；血量过半前摇更快、连拳多一下。
- 四关的关卡配置集中在 `game/street/chapter-data.ts`，剧本集中在 `game/street/story-data.ts`；剧本按章节和所选角色取数据，不再靠「不是第一关就当第二关」的分支。

- 三个可选角色：陈野（均衡）、阿拓（高生命、重拳和强投）、小满（快速移动和攻击）。
- 南桥夜市一关，三个清场区域，10 个小兵、一个铁头 Boss。
- 连拳与第三击重击、跳跃与空中踢击、近身抓投并撞伤后方敌人、50 怒气的范围绝招。
- 小兵：拳手、游斗快手、壮汉。通过速度、生命、攻击前摇和伤害区分。
- 敌人攻击前摇、最多两人同时准备出手、受击硬直、击退、短暂命中停顿、连击计数和合成音效。
- 铁头蓄力冲撞，预警、可躲避的冲撞路径和结束后的反击窗口。
- 第二段街道的回血食物；关前、Boss 前与过关剧情；失败重试和重新选角。
- 手机摇杆及五个按钮；电脑 WASD/方向键 + J/K/L/I/U；失焦自动暂停。
- 选人页四个关卡入口，窄屏折成两行两列；通关按钮只在下一关存在时出现，第四关结束显示原型完结说明。

## 操作

- WASD / 方向键：移动；J：攻击（可按住）；K / 空格：跳跃。
- L：抓投，靠近小兵使用（Boss 不可抓投）；I：50 怒气绝招。
- Esc：暂停 / 继续。手机推荐横屏。

## 代码

- `game/street/simulation.ts`：独立战斗模拟、碰撞与命中规则、敌人行为、清场流程。
- `game/street/renderer.ts`：Phaser 480×270 像素画布、原创程序绘制角色与场景。
- `app/nanqiao/page.tsx`：选角、剧情、HUD、键盘和多点触控输入、声音。
- `game/street/simulation.test.mjs`：命中范围、抓投碰撞、怒气、跳跃、完整关卡状态流程、Boss 与重试测试。

## 原型边界

这版用程序绘制的像素角色和动作姿势，没有最终逐帧美术。角色共用基础动作，只在速度、伤害、生命、投掷能力上有差异；小满尚无单独快踢动作集。抓投人的连带伤害按投掷方向和范围结算，不是完整飞行碰撞模拟。小兵游斗行为仍是简化版本。四关共用同一套街道尺寸和三段推进结构，第三关的天桥、第四关的擂台都用背景表现高度，没有真正的高低层、楼梯或坠落。第三、四关沿用已有的四种小兵，没有为赛场新做兵种。存档、短期武器、桌椅摊位破坏、Poki SDK 尚未实现。木箱不阻挡人物走位，也暂不能用拳头直接打碎。

第二关验证：15 项模拟测试覆盖关卡衔接、重试、Boss 通关、举放投箱、范围伤害、补给、掩护、跳跃免伤、敌人前摇。浏览器实际键盘举箱与触屏投箱通过；844×390 实机画面、390×844 和 568×320 设置面板已检查，未发现运行时错误。真实手机发热与手感仍需真机试玩。

第三、四关验证：114 项模拟测试（新增 13 项在 `game/street/chapter.test.mjs`）、TypeScript 检查、Pages 构建通过。新增测试覆盖四关串联与到此为止、两关全流程通关、失败重试留在本关、两个 Boss 的招式轮换与必然开放的破绽、1/30～1/120 帧率下的破绽时长、减伤倍率、过半血的连拳段数、练习场 Boss 名字、剧本对三个角色的完整覆盖。桌面浏览器已实际进入第三、四关并确认背景、HUD 和陆川的侧移／破绽表现；未做真机手感验收，也未测试触屏下的新关卡。
